INDEPENDENT-SEED RUNS FOR MONTE CARLO STABILITY
===============================================

Why this update is needed
-------------------------
The existing runners use fixed archival seeds. That is correct for exact
reproduction, but rerunning with those same seeds does not assess Monte Carlo
error. Add a seed-offset option so a second, independent full run can be made
without editing simulation source files.

Required runner changes
-----------------------
1. Uncensored Simulations/run_tables_1_6.R

Add seed_offset = 0L to the option list, accept --seed-offset=N in the argument
parser, and validate that it is a single nonnegative integer. After creating
selected_plan, apply:

  selected_plan$Seed <- selected_plan$Seed + options$seed_offset

Because run_manifest.csv already records selected_plan$Seed, the effective
seeds will then be archived automatically.

2. Censored Simulations/run_tables_7_10.R

Add seed_offset = 0L to opt, accept and validate --seed-offset=N, and replace:

  point_seed <- 5401L
  ci_seed <- 5402L

with:

  point_seed <- 5401L + opt$seed_offset
  ci_seed <- 5402L + opt$seed_offset

The existing manifest and run-settings output will then record the effective
point-estimation and confidence-interval seeds.

3. run_all.R

The supplied run_all.R already accepts --seed-offset=N, passes it to both
simulation runners, and passes 2026 + seed_offset to the real-data script.
Copy that supplied file after making changes 1 and 2 above.

Recommended runs
----------------
Run A, preserving the archival manuscript seeds:

  Rscript --vanilla run_all.R --mode=full --cores=4 --seed-offset=0 \
    --output-dir=results/stability_run_A

Run B, using a disjoint seed set:

  Rscript --vanilla run_all.R --mode=full --cores=4 --seed-offset=100000 \
    --output-dir=results/stability_run_B

Compare corresponding table cells and complete
MONTE_CARLO_STABILITY_RECORD.txt. Do not replace the archival Run A outputs in
the manuscript merely because Run B differs slightly; use the comparison to
show whether conclusions and method rankings are stable.
