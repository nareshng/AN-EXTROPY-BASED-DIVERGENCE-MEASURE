BIOMETRICAL JOURNAL REPRODUCIBILITY CHECKLIST - PRACTICAL SUMMARY
=================================================================

What must be true before resubmission
-------------------------------------
1. A co-author must reproduce every submitted table, figure and reported
   computational result from the supplement on a separate clean machine.
2. Code, data, intermediate results, logs and a README must be supplied in one
   ZIP file, unless oversized files are deposited in a stable external archive.
3. The README must be TXT, HTML or PDF and must state exact software versions,
   execution order, data provenance, licensing and the folder structure.
4. Every random analysis must use recorded seeds. Independent-seed reruns must
   also show that Monte Carlo error does not change substantive conclusions.
5. Long simulations must include intermediate results and support fast spot
   checks of selected settings without rerunning the complete study.

What the code must do
---------------------
- Provide master scripts that iterate over settings and collect results.
- Require no repeated manual edits or manual copying from console output.
- Save manuscript-matching tables and figures under descriptive numbered names.
- Separate reusable functions from analysis drivers.
- Avoid duplicate, obsolete and commented-out code.
- Avoid package installation, global-workspace deletion and absolute paths.
- Use documented functions, consistent formatting and portable relative paths.
