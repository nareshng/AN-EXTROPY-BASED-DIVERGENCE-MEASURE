DATA PROVENANCE
====================================


1. Veteran lung cancer data
---------------------------
Analysis source: survival::veteran
Documentation: Run help("veteran", package = "survival") in the pinned
environment.
Original study citation: Kalbfleisch and Prentice (1980), as cited in the
manuscript.
Package version used: survival 3.5-8


2. NCCTG lung cancer data
-------------------------
Analysis source: survival::lung
Documentation: Run help("lung", package = "survival") in the pinned
environment.
Original study citation: Loprinzi et al. (1994), as cited in the manuscript.
Package version used: survival 3.5-8


3. GBSG2 breast cancer data
---------------------------
Required analysis source: TH.data::GBSG2
Documentation: Run help("GBSG2", package = "TH.data") in the pinned
environment.
Original study citation: Schumacher et al. (1994), as cited in the manuscript.
Package version used: TH.data 1.1-2


4. MRI image data
-----------------
Stated source:
https://www.kaggle.com/datasets/sartajbhuvaji/brain-tumor-classification-mri/data

Files analysed: NT1.jpg-NT3.jpg, BT1.jpg-BT3.jpg and MT1.jpg-MT3.jpg.
