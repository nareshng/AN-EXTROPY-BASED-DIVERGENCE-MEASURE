REPRODUCIBLE R ENVIRONMENT
==========================

The final repository must contain a generated renv.lock. Do not hand-edit or
invent this file.

Reference versions currently stated by the project
--------------------------------------------------
R 4.6.1
emplik 1.3-3
survival 3.5-8
TH.data 1.1-2
jpeg 0.1-10
ggplot2 3.4.4
survminer 0.4.9

Procedure on the machine used for the final manuscript run
----------------------------------------------------------
1. Install R 4.6.1.
2. Open R in the repository root.
3. Install renv once if needed:

   install.packages("renv")

4. Initialize an isolated environment:

   renv::init(bare = TRUE)

5. Install the exact direct dependencies:

   renv::install(c(
     "emplik@1.3-3",
     "survival@3.5-8",
     "TH.data@1.1-2",
     "jpeg@0.1-10",
     "ggplot2@3.4.4",
     "survminer@0.4.9"
   ))

6. Record all resolved direct and transitive dependencies:

   renv::snapshot(type = "all")

7. Commit renv.lock. Do not commit the local renv package cache.
8. Test restoration in a fresh clone:

   renv::restore()
   Rscript --vanilla capture_environment.R --strict --output-dir=environment_test

9. If a listed historical package release is unavailable from the configured
   repository, record the archive URL or Git commit in README.txt. Never replace
   it silently with a newer version.
