File to complete and then copy

Real Data Analysis/Images/image_manifest.csv only after replacing every
AUTHOR_MUST_COMPLETE value with verified information from the original data
source.

Important
---------
- README.txt contains fields marked AUTHOR ACTION REQUIRED. Complete them
  before submission.
- Do not claim that the complete workflow reproduces the manuscript until the
  full run and independent clean-machine run have both passed.
- Do not state that Tables 9-10 include sample sizes 200 or 500. The current
  manuscript and code use sample-size pairs (30,40), (70,50), and (100,100).
- The supplied scripts were statically reviewed but could not be executed in
  this environment because Rscript was unavailable.

Recommended order
-----------------
1. Complete the image manifest and DATA_PROVENANCE.txt.
2. Create and commit renv.lock using ENVIRONMENT_SETUP.txt.
3. Copy the helper scripts and README.txt into the repository root.
4. Run a quick check:
     Rscript --vanilla run_all.R --mode=quick --cores=2 --seed-offset=0
5. Run the full workflow:
     Rscript --vanilla run_all.R --mode=full --cores=4 --seed-offset=0
6. Complete CLEAN_MACHINE_TEST_RECORD.txt on a second machine.
7. Implement INDEPENDENT_SEED_RUNS.txt and complete
   MONTE_CARLO_STABILITY_RECORD.txt using independent-seed runs.
8. Run verify_submission.R against the full-run directory.
9. Replace the manuscript Data Availability Statement using the text in
   MANUSCRIPT_REVISIONS_REQUIRED.txt.
10. Create one submission ZIP containing source code, README.txt, renv.lock,
   final paper outputs, intermediate simulation results, logs, manifests,
   session information, and the completed clean-machine record.
